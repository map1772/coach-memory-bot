# Тренер, который помнит

Демонстрационный Telegram-бот: ответы строятся на профиле конкретного человека
и на истории разговора, а не на шаблоне.

Что показывает:

- анкета профиля на входе, дальше ответы опираются на неё
- факты из свободной речи попадают в профиль сами, без анкеты
- уточняющий вопрос задаётся только когда данных реально не хватает
- тон и глубина меняются под уровень собеседника
- отвлечённые вопросы не ломают диалог

Команды: `/profile` что бот знает о вас, `/why` почему ответ был таким,
`/demo` один вопрос от лица двух разных людей, `/reset` начать заново.

Стек: Python, aiogram 3, PostgreSQL, structured output с валидацией через Pydantic.
